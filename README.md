# Control de Bienes (web)

App web de Control de Bienes de la Sociedad Bíblica Peruana. Se usa solo desde una PC.

- **Dirección:** https://cvalienteg.github.io/control-bienes-web/
- **Datos:** en Firebase (proyecto `control-bienes-sbp`). Solo los lee y modifica quien tenga una cuenta activada por el administrador (ver `firestore.rules`).
- **Este repositorio** solo tiene la app y las imágenes de los planos. El código fuente y los archivos de trabajo están en el repositorio privado `control-bienes`.

**Para actualizar la app:** sube el nuevo `index.html` (Add file → Upload files → Commit changes). Los datos no se tocan.
